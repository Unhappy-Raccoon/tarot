# Каталог визуальных референсов

## Источник истины

Полная библиотека сгенерированных макетов, SVG-прототипами и контактными листами передана владельцу в архиве `Personal_Cosmic_Journal_Все_макеты_по_разделам.zip`. Сами бинарные изображения пока не включены в этот Git-коммит.

Ниже перечислены утверждённые файлы, которые следует разместить в `assets/references/` при добавлении оптимизированных превью:

| File | Раздел | Примечание |
|---|---|---|
| `00-design-system.webp` | Дизайн-система | Пользовательский референс палитры и типографики |
| `01-home.webp` | Главная | Утверждённый экран; в PRD предусмотрен блок гороскопа дня |
| `02-tarot-selection.webp` | Таро — выбор | Три стартовых расклада |
| `03-tarot-result.webp` | Таро — результат | Утверждённая композиция результата |
| `04-natal-chart.webp` | Натальная карта | Значения в макете демонстрационные |
| `05-ai-astrologer.webp` | AI-астролог | Утверждённая тёмная версия чата |
| `06-journal.webp` | Журнал | Утверждённый экран истории |
| `07-profile-premium.webp` | Профиль и Premium | Последняя утверждённая тёмная версия с приглушённой фиолетовой атмосферой |

## Правила использования

1. При реализации сверять композицию, расположение блоков, цвета, типографику и состояния с утверждёнными макетами.
2. Оптимизированные превью в GitHub будут предназначены для просмотра и не заменят полноразмерные оригиналы.
3. Отклонённые и промежуточные генерации хранятся в отдельном архиве истории и не являются источником истины.
4. Демонстрационные имена, даты рождения и прочие персональные значения из макетов не использовать как реальные пользовательские данные.
5. Не использовать фирменные элементы или ассеты Co–Star и иных сторонних продуктов.

# Каталог визуальных референсов

## Источник истины

Полная библиотека макетов, SVG-прототипов, контактных листов и промежуточных генераций передана владельцу в архиве `Personal_Cosmic_Journal_Все_макеты_по_разделам.zip`.

В репозитории размещён лёгкий обзорный контактный лист, объединяющий восемь утверждённых направлений:

- `assets/references/approved-reference-contact-sheet.webp`

Контактный лист — быстрый ориентир для команды, а не замена полноразмерным оригиналам. Основной UI source of truth остаются утверждённые макеты из архива и пользовательские правки.

## Правила использования

1. Сверять композицию, расположение блоков, цвет, типографику и состояния с оригинальными утверждёнными макетами.
2. Не трактовать контактный лист как pixel-perfect спецификацию.
3. Отклонённые и промежуточные генерации не являются источником истины.
4. Демонстрационные имена, даты рождения и персональные значения не использовать как реальные пользовательские данные.
5. Не использовать чужие фирменные элементы или ассеты Co–Star и иных сторонних продуктов.

# Каталог визуальных референсов

Полноразмерная библиотека макетов передана владельцу отдельным архивом. На этом этапе создаётся каталог ожидаемых файлов в `assets/references/`; бинарные изображения будут добавлены отдельной загрузкой, не через UTF-8 Git tree content.

| File | Раздел | Примечание |
|---|---|---|
| `00-design-system.webp` | Утверждённая дизайн-система | Пользовательский референс палитры |
| `01-home.webp` | Главная | Утверждённый экран; в PRD предусмотрен блок гороскопа дня |
| `02-tarot-selection.webp` | Таро — выбор | Три стартовых расклада |
| `03-tarot-result.webp` | Таро — результат | Утверждённая композиция результата |
| `04-natal-chart.webp` | Натальная карта | Демонстрационные значения |
| `05-ai-astrologer.webp` | AI-астролог | Утверждённая тёмная версия чата |
| `06-journal.webp` | Журнал | Утверждённая история |
| `07-profile-premium.webp` | Профиль и Premium | Последняя утверждённая версия |

Превью предназначены для просмотра в GitHub, а не для pixel-perfect реализации. Отклонённые генерации не являются источником истины. Демонстрационные персональные данные на макетах не использовать как настоящие.

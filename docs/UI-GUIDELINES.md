# UI Guidelines — утверждённая визуальная система

Источник истины: утверждённый пользователем макет визуальной концепции Этапа 2 и последующие правки экранов профиля/Premium.

## Палитра

| Token | Hex | Применение |
|---|---|---|
| `--color-night` | `#0B0A14` | Основной почти чёрный ночной фон |
| `--color-cosmic-violet` | `#5847B8` | Космический фиолетовый, вторичный оттенок |
| `--color-lavender` | `#A392D8` | Приглушённое лавандовое свечение |
| `--color-milk` | `#F1DCCB` | Молочный текст и светлые элементы |
| `--color-gold` | `#D9B983` | Золотой акцент, тонкие обводки и иконки |

Значения фиолетового, лавандового и молочного приблизительно сняты с утверждённого референса; золото согласовано как акцент. Финальный визуальный ориентир: почти чёрная основа, молочный текст и шампанское золото. Фиолетовый не должен доминировать — преимущественно дальние космические облака и едва заметные фоновые градиенты. Карточки — тёмные, не заливать интерфейс ярким фиолетовым.

## Типографика

- **Playfair Display** — заголовки и крупные editorial акценты.
- **Inter** — навигация, основной текст, подписи, формы и элементы управления.

Файлы шрифтов в репозиторий не включены. Источник и лицензирование шрифтов согласовать при реализации.

## Композиция и поверхности

- Премиальный редакционный минимализм.
- Большие заголовки и свободное пространство.
- Строгая сетка, умеренные скругления, тонкие золотые контуры.
- Читаемый текст с достаточным контрастом.
- Мягкое лунное/звёздное свечение, без чрезмерно ярких фиолетовых заливок.
- Единый набор иконок и нижней навигации.

## Анимации

CSS 3D flip для Таро и астрологических карточек; ориентир 600–700 мс, ось Y, небольшое приподнимание и сдержанное золотое свечение. Поддерживать `prefers-reduced-motion`: при запросе уменьшения движения менять сторону без интенсивного вращения/свечения.

## Доступность

Учитывать touch targets, mobile safe areas, viewport Telegram WebApp, контраст и не полагаться только на цвет для состояний.

## Запреты

Не копировать чужие фирменные элементы, изображения или композицию Co–Star и иных сторонних продуктов.
